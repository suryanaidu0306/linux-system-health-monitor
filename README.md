# Linux System Health Monitor

## Description
A Bash script to monitor the health of a Linux system.

## Features
- Date and Time
- Current User
- Hostname
- System Uptime
- RAM Usage
- Disk Usage
- CPU Information
- Top Running Processes

## Commands Used
- date
- whoami
- hostname
- uptime
- free
- df
- lscpu
- ps

## Run

```bash
chmod +x system_health.sh
./system_health.sh
```
